# ⛽ tankeschoen

Eine C#-Anwendung, die Autofahrern dabei hilft, günstige Tankstellen in der Umgebung zu finden und Kraftstoffpreise zu vergleichen.

---

## ✨ Features

- 📍 **Günstig Tanken:** Schnelle Anzeige und Vergleich aktueller Spritpreise.
- 🗺️ **Standort- & Umgebungssuche:** Übersichtliche Darstellung relevanter Tankstellen in der Nähe.
- 📊 **Preisvergleich:** Effiziente Auswertung von Preisdaten für die beste Entscheidung beim Tanken.
- 🏗️ **Saubere Code-Struktur:** Objektorientierte Logik in C# zur Verarbeitung von Standort- und Preisdaten.

---

## 🛠️ Tech Stack

- **Sprache:** C# (.NET)
- **Umgebung:** Visual Studio
- **Architektur:** Objektorientierte Datenmodellierung
